# Sistema de Gestión de Backorder PCM

Sistema completo para la gestión eficiente de backorders en plantas industriales de fabricación de etiquetas.

## 🚀 Inicio Rápido

**Solo necesitas hacer doble clic en:** `INICIAR.bat`

El sistema se iniciará automáticamente y abrirá tu navegador.

**Credenciales por defecto:**
- Usuario: `admin`
- Contraseña: `admin123`

**Modos de inicio:**
- `dev` (desarrollo): frontend con Vite en `http://localhost:3000` (auto-reload)
- `prod` (produccion): frontend con nginx en `http://localhost:3001`

## 📁 Scripts Disponibles

- **INICIAR.bat** - Inicia todo el sistema automáticamente
- **DETENER.bat** - Detiene todos los servicios
- **estado.ps1** - Ver estado del sistema
- **ver-logs.ps1** - Ver logs en tiempo real
- **reset.ps1** - Reiniciar completamente el sistema

## 🎯 Características

- Gestión de Backorders con priorización automática
- Integración con ERPs (INFOR Syteline, MONGUS, Intranet)
- Control de Inventario de Materiales
- Seguimiento de Producción
- Gestión Logística
- Dashboard en Tiempo Real

## ⚙️ Requisitos

- Windows 10/11
- Docker Desktop
- 4GB RAM disponible

Edita `config.yaml` para configurar tus sistemas ERP y credenciales.
